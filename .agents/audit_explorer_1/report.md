### 1.2 R2: Non-Inferiority Verification & Formal Statistical Proof

#### Preregistration Contract Inspection (`AS-03` & `AS-12`)
1. **`AS-03` Section 4**:
   - Stated Alternative Hypothesis ($H_1$): *"Condition A4 (`RECENCY_RELEVANCE`) achieves non-inferior MRR compared to A7 (`FULL_TRI_FACTOR`) within $\Delta \le 0.02$, proving that static importance scores add negligible marginal value over semantics and recency."*
   - Stated Null Hypothesis ($H_0$): *"Importance weighting is strictly necessary ($\text{MRR}_{A7} - \text{MRR}_{A4} \ge +0.05, p < 0.0025$)."*
   - Statistical Test: Paired Wilcoxon signed-rank test with Bonferroni correction ($\alpha_{\text{adjusted}} = 0.01 / 7 = 0.001429$).
2. **`AS-12` Section 2.1**:
   - Power Contract: Target effect size Cohen's $d = 0.35$; family-wise error rate controlled via Bonferroni correction $\alpha_{\text{adjusted}} = 0.01 / 7 = 0.001429$; sample size $N = 100$ standardized queries from `SimLab-MemBench-500` delivering $86.4\%$ statistical power.
3. **Margin Discrepancy Note**:
   - `AS-03` contains a textual specification discrepancy between $H_1$ (which specifies margin $\delta = 0.02$) and $H_0$ (which specifies $\text{MRR}_{A7} - \text{MRR}_{A4} \ge +0.05$, corresponding to margin $\delta = 0.05$). To ensure audit completeness, both $\delta = 0.02$ and $\delta = 0.05$ are formally evaluated below.

#### Harness Adjudication Audit (`run_exp_ab_01_comp.py` & `exp_ab_01_comp_results.json`)
Inspection of lines 280–286 of `run_exp_ab_01_comp.py` reveals how the execution harness adjudicated these hypotheses:
```python
a4_delta = comparisons["A4"]["delta_mrr"]
a4_p = comparisons["A4"]["p_value"]
h1_non_inferior = (a4_delta >= -0.02)
h0_satisfied = (condition_summaries["A7"]["mrr_mean"] - condition_summaries["A4"]["mrr_mean"]) >= 0.05 and a4_p < 0.0025
```
This produced the output in `exp_ab_01_comp_results.json`:
```json
"hypothesis_testing": {
  "h1_non_inferiority_a4_vs_a7": {
    "threshold_delta": 0.02,
    "observed_delta": 0.40608528381806297,
    "verdict": "CONFIRMED"
  },
  "h0_importance_necessity": {
    "threshold_delta": 0.05,
    "observed_delta": -0.40608528381806297,
    "p_value": 2.135556870734694e-09,
    "verdict": "REJECTED"

```
**Critical Defect Identified**:
- **Zero Formal Non-Inferiority Testing**: The harness did not calculate a one-sided test statistic (such as a shifted t-test or shifted Wilcoxon test) and did not calculate a lower confidence bound against $-\delta$. It merely checked if the point estimate was $\ge -0.02$.
- **Conflated Two-Sided p-value**: In `h0_importance_necessity`, the harness reported $p = 2.1356 \times 10^{-9}$. That p-value was taken directly from the two-sided Wilcoxon test of whether $\text{MRR}_{A4} \ne \text{MRR}_{A7}$. It was not a test of the directional null hypothesis $\text{MRR}_{A7} - \text{MRR}_{A4} \ge +0.05$. Reporting this p-value as the basis for rejecting $H_0$ was methodologically invalid.

#### Rigorous Mathematical Calculation of Formal Non-Inferiority
Let $d_i = \text{MRR}_{A4, i} - \text{MRR}_{A7, i}$ for each paired query $i = 1, \dots, 100$.
- Sample Size: $N = 100$
- Sample Mean Paired Difference: $\bar{d} = +0.406085$
- Sample Standard Deviation of Paired Difference: $s_d = 0.434689$
- Standard Error of Paired Difference: $\text{SE} = \frac{s_d}{\sqrt{100}} = 0.043469$
- Degrees of Freedom: $df = 99$

##### Test Formulation
- Null Hypothesis ($H_0$): Condition A4 is inferior to A7 by more than margin $\delta$:
  $$\mu_d = \mu_{A4} - \mu_{A7} \le -\delta$$
- Alternative Hypothesis ($H_1$): Condition A4 is non-inferior to A7:
  $$\mu_d = \mu_{A4} - \mu_{A7} > -\delta$$

##### 1. One-Sided Paired t-Test Statistics
The test statistic is given by $t = \frac{\bar{d} - (-\delta)}{\text{SE}}$:
- **Under Margin $\delta = 0.02$**:
  $$t = \frac{0.406085 - (-0.02)}{0.043469} = \frac{0.426085}{0.043469} = \mathbf{9.8021}$$
  $$p_{\text{one-sided}} = 1 - F_t(9.8021, df=99) = \mathbf{1.1102 \times 10^{-16}}$$
- **Under Margin $\delta = 0.05$**:
  $$t = \frac{0.406085 - (-0.05)}{0.043469} = \frac{0.456085}{0.043469} = \mathbf{10.4922}$$
  $$p_{\text{one-sided}} = 1 - F_t(10.4922, df=99) < \mathbf{10^{-16}} \quad (\approx 0.0000)$$

##### 2. One-Sided Shifted Wilcoxon Signed-Rank Test Statistics
Testing the median of shifted differences $d_i - (-\delta) > 0$:
- **Under Margin $\delta = 0.02$**:
  $$W = \mathbf{4394.0}, \quad p_{\text{one-sided}} = \mathbf{6.4934 \times 10^{-11}}$$
- **Under Margin $\delta = 0.05$**:
  $$W = \mathbf{4752.0}, \quad p_{\text{one-sided}} = \mathbf{9.4090 \times 10^{-15}}$$

##### 3. Exact Lower Confidence Bounds (LCB)
The $(1 - \alpha)$ one-sided lower confidence bound is $\text{LCB} = \bar{d} - t_{\text{crit}} \times \text{SE}$. Note that the LCB is an intrinsic property of the observed sample distribution and is independent of the margin threshold $\delta$:
- **Standard $\alpha = 0.05$ (95% One-Sided LCB)**:
  $$t_{\text{crit}, 0.05} = 1.660551 \implies \text{LCB}_{95\%} = 0.406085 - (1.660551 \times 0.043469) = \mathbf{+0.333910}$$
- **Conservative $\alpha = 0.01$ (99% One-Sided LCB)**:
  $$t_{\text{crit}, 0.01} = 2.364606 \implies \text{LCB}_{99\%} = 0.406085 - (2.364606 \times 0.043469) = \mathbf{+0.303299}$$
- **Bonferroni-Adjusted $\alpha = 0.001429$ (99.857% One-Sided LCB)**:
  $$t_{\text{crit}, \text{Bonf}} = 3.058988 \implies \text{LCB}_{\text{Bonf}} = 0.406085 - (3.058988 \times 0.043469) = \mathbf{+0.273114}$$

##### Formal Non-Inferiority Adjudication Decision
- **Decision Criterion**: Reject $H_0$ if $\text{LCB} > -\delta$.
- **Audit Finding**: Under all significance thresholds ($\alpha = 0.05, 0.01, 0.001429$) and under both margins ($\delta = 0.02, 0.05$):
  $$\text{LCB}_{\text{Bonf}} = +0.273114 \gg -0.02 \quad (\text{and } \gg -0.05)$$
- **Superiority Corollary**: Furthermore, because $\text{LCB}_{\text{Bonf}} = +0.273114 > 0.0$, the evidence does not merely satisfy non-inferiority; it proves that Condition A4 is **statistically superior** to Condition A7 by at least $+0.2731$ MRR at family-wise error control $\alpha = 0.01$.
- **Formal Status**: `NON_INFERIORITY_FORMALLY_CONFIRMED_SUPERIORITY_OBSERVED`.

### 1.3 R3: Importance-Necessity Interpretation & Directional Failure Analysis

#### The Empirical Contradiction
The classical generative agents memory architecture (Park et al., 2023) presumes that memory retrieval scoring must incorporate static prompt-assigned importance ($s = \alpha s_{rec} + \beta s_{rel} + \gamma s_{imp}$) to prioritize high-salience experiences. Preregistration document `AS-03` formulated the null hypothesis:
$$H_0: \text{Importance weighting is strictly necessary } (\text{MRR}_{A7} - \text{MRR}_{A4} \ge +0.05, p < 0.0025)$$
The empirical results revealed a stark contradiction:
- Condition A4 (`RECENCY_RELEVANCE`, $\alpha=0.3, \beta=0.7, \gamma=0.0$): **MRR = 0.5002**
- Condition A7 (`FULL_TRI_FACTOR`, $\alpha=0.2, \beta=0.5, \gamma=0.3$): **MRR = 0.0941**
- Paired Difference ($A4 - A7$): **$\Delta \text{MRR} = +0.4061$** ($+431.3\%$ relative increase over A7)
- Paired Difference ($A7 - A4$): **$\Delta \text{MRR} = -0.4061$** ($81.2\%$ relative degradation)

#### Statistical Dimension Decomposition
- **Effect Direction**: Severely negative for A7 relative to A4. A7 does not merely fail to outperform A4 by $+0.05$; it collapses to less than a fifth of A4's retrieval precision.
- **Effect Magnitude**: Large-to-extreme effect size. Cohen's $d = +0.9342$ ($s_d = 0.4347$).
- **95% Confidence Interval**: Paired two-sided 95% CI is $[+0.3209, +0.4913]$. The entire confidence interval is separated from zero by more than $+0.32$ MRR.
- **Paired Hypothesis Test**: Wilcoxon signed-rank test $W = 784.0$, $p = 2.1356 \times 10^{-9}$ ($p < \alpha_{\text{Bonf}} = 0.001429$).

#### Addressing the P-Value Fallacy
In naive hypothesis testing, an analyst observing $p = 2.14 \times 10^{-9} < 0.0025$ might mechanically declare: *"The null hypothesis was rejected at $p < 0.0025$, confirming the experimental design."*
This interpretation is completely invalid. The null hypothesis was directional: it asserted that A7 would exceed A4 by at least $+0.05$. The observed p-value rejected equality between A4 and A7 in favor of **A4 vastly outperforming A7**. 
This is not a routine rejection of a null hypothesis; it is an **empirical falsification of the theoretical foundation of tri-factor scoring**. The tri-factor condition (A7) suffered a catastrophic directional failure.

#### Mechanistic Root Cause of Directional Failure
Why did adding $\gamma = 0.3$ importance cause an $81.2\%$ collapse in retrieval accuracy? Forensic inspection of score distributions and code logic reveals four interrelated mechanisms:

```
[Prompt-Generated Importance (4.0 - 6.0)]
               │
               ▼
[Orthogonal to Query Need] ──► 37.7% of distractors have higher importance than target
               │
               ▼
[Per-Query Min-Max Normalization] ──► Stretches distractor range across [0.0, 1.0]
               │
               ▼
[Weight Application (gamma = 0.3)] ──► High-importance distractors gain +0.27 to +0.30 boost
               │
               ▼
[Retrieval Displacement] ──► Ground-truth episodic memories pushed out of Top-5
```

1. **Orthogonal Distractor Advantage**:
   - Importance scores in the benchmark memory store (500 memories) range from $4.01$ to $6.00$ ($\text{mean} = 5.0029, \text{std} = 0.5733$).
   - The ground-truth target memories have a mean importance of $5.2364$ ($\text{std} = 0.4583$).
   - Across the 100 queries, an average of **188.4 distractors out of 500 (37.7%)** possess a higher raw importance score than the target memory!
   - Because importance is assigned statically at memory creation time, it is completely orthogonal to the information need of any specific query.
2. **Min-Max Normalization Scale Compression**:
   - The harness applies per-query min-max normalization across all candidates:
     $$s_{\text{norm}} = \frac{s - \min(s)}{\max(s) - \min(s)}$$
   - Across the 500-node memory store, the raw importance range is narrow ($6.00 - 4.01 = 1.99$). Normalizing this range stretches it over $[0.0, 1.0]$.
   - With weight $\gamma = 0.3$, importance contributes up to $+0.300$ to the total score.
   - A completely irrelevant distractor with raw importance $5.80$ receives a normalized score of $\approx 0.90$, contributing $+0.270$ to its total score.
   - A target memory with raw importance $5.00$ (average) receives a normalized score of $\approx 0.50$, contributing only $+0.150$.
   - The distractor obtains an unearned $+0.120$ advantage over the target memory solely from static importance, easily overcoming semantic similarity differences and pushing the target out of the top ranks.
3. **Stratified Query Analysis**:
   - **Recency-Sensitive Queries ($N=40$)**: Target memories require temporal prioritization. A4 achieves MRR = **$0.7229$** (NDCG@5 = $0.7925$). A7 collapses to MRR = **$0.0904$** (NDCG@5 = $0.0193$)—a catastrophic drop of **$-0.6325$ MRR**! Distractors with high static importance completely displace recent memories.
   - **Temporal-Conflict Queries ($N=20$)**: Queries where newer state contradicts older state. A4 achieves perfect retrieval: MRR = **$1.0000$** (NDCG@5 = $1.0000$). A7 collapses to MRR = **$0.1549$** (NDCG@5 = $0.1861$)—a drop of **$-0.8451$ MRR**!
   - **Relevance-Dominant Queries ($N=40$)**: A2 (`RELEVANCE_ONLY`) achieves perfect retrieval: MRR = **$1.0000$**. When recency is added in A4 ($\alpha=0.3$), older relevant targets drop to MRR = $0.0277$. When importance is added in A6 ($\beta=0.7, \gamma=0.3$, no recency), MRR drops from $1.0000$ to **$0.3838$** (a $61.6\%$ loss), directly demonstrating that importance acts as pure noise against semantic retrieval.
4. **Continuous Simplex Sweep Evidence**:
   - The 66-point 2D continuous simplex sweep ($\alpha + \beta + \gamma = 1.0$, step $= 0.1$) provides definitive mathematical proof of this dynamic:
     - **Global Optimum**: $(\alpha=0.7, \beta=0.3, \gamma=0.0)$ with **$\text{MRR} = 0.6036$**.
     - **Global Minimum**: $(\alpha=0.0, \beta=0.0, \gamma=1.0)$ with **$\text{MRR} = 0.0086$**.
     - **Gamma Gradient**: As $\gamma$ increases, MRR degrades monotonically across all slices. At $\gamma=0.0$, mean MRR across all points is $0.5134$; at $\gamma=0.3$, mean MRR drops to $0.1492$; at $\gamma \ge 0.5$, mean MRR is $< 0.05$.
   - **Conclusion**: Under offline semantic retrieval with min-max normalization, prompt-based static importance is not a beneficial inductive bias; it is an uncalibrated distractor amplifier that degrades retrieval precision.

### Section B: Non-Inferiority Verification

#### B.1 Preregistered Specifications (`AS-03` & `AS-12`)
The experimental protocol for `EXP-AB-01-COMP` preregistered the following evaluation parameters:
- Primary Outcome: Mean Reciprocal Rank (MRR) across $N = 100$ standardized queries from `SimLab-MemBench-500`.
- Experimental Pair: Condition A4 (`RECENCY_RELEVANCE`: $\alpha=0.3, \beta=0.7, \gamma=0.0$) versus Condition A7 (`FULL_TRI_FACTOR`: $\alpha=0.2, \beta=0.5, \gamma=0.3$).
- Preregistered Margins:
  - $\delta = 0.02$ (specified in `AS-03` Section 4 $H_1$)
  - $\delta = 0.05$ (specified in `AS-03` Section 4 $H_0$)
- Significance Threshold: Family-wise error rate controlled via Bonferroni correction across 7 pairwise comparisons against A7:
  $$\alpha_{\text{adjusted}} = \frac{0.01}{7} = 0.00142857 \approx 0.00143$$

#### B.2 Empirical Paired Differences
Let $d_i = \text{MRR}_{A4, i} - \text{MRR}_{A7, i}$ for each query $i \in \{1, \dots, 100\}$:
- $N = 100$
- Mean Paired Difference: $\bar{d} = +0.406085$
- Standard Deviation of Differences: $s_d = 0.434689$
- Standard Error: $\text{SE} = \frac{0.434689}{\sqrt{100}} = 0.043469$
- Degrees of Freedom: $df = 99$

#### B.3 Formal Hypothesis Testing Results

##### One-Sided Test for Non-Inferiority
- **Hypothesis**: $H_0: \mu_d \le -\delta \quad \text{vs} \quad H_1: \mu_d > -\delta$

```
Inferiority Region          Non-Inferiority Region
<====================|------------------------------------------->
                   -delta = -0.02     0.0     LCB = +0.2731   Mean = +0.4061
```

- **Evaluation Under Margin $\delta = 0.02$**:
  - Test Statistic: $t = \frac{0.406085 - (-0.02)}{0.043469} = \mathbf{9.8021}$
  - One-Sided P-Value: $p_t = 1 - F_t(9.8021, 99) = \mathbf{1.1102 \times 10^{-16}}$
  - Shifted Wilcoxon Signed-Rank Test: $W = \mathbf{4394.0}, \quad p_W = \mathbf{6.4934 \times 10^{-11}}$

##### Lower Confidence Bound Analysis
- **95% One-Sided Lower Confidence Bound ($\alpha = 0.05$)**:
  $$\text{LCB}_{95\%} = \bar{d} - (t_{0.95, 99} \times \text{SE}) = 0.406085 - (1.660551 \times 0.043469) = \mathbf{+0.333910}$$

1. **Non-Inferiority Established**: The lower bound of the Bonferroni-corrected confidence interval ($\text{LCB}_{\text{Bonf}} = +0.2731$) exceeds the preregistered non-inferiority margins $-\delta = -0.02$ and $-\delta = -0.05$ by more than $0.29$ MRR points. ### Section C: Importance-Necessity Interpretation

#### C.1 The Empirical Disconfirmation
The empirical findings of `EXP-AB-01-COMP` provide an unambiguous disconfirmation of the necessity of importance weighting in generative agent memory architectures under standardized retrieval conditions:
- **Condition A4 (`RECENCY_RELEVANCE`)**: $\text{MRR} = 0.5002 \pm 0.4481$
- **Condition A7 (`FULL_TRI_FACTOR`)**: $\text{MRR} = 0.0941 \pm 0.0738$
- **Net Delta**: $\Delta \text{MRR} = +0.4061$ ($+431.3\%$ advantage for A4)
- **Effect Size**: Cohen's $d = +0.9342$
- **95% Confidence Interval**: $[+0.3209, +0.4913]$
- **Paired Wilcoxon Test**: $W = 784.0, p = 2.1356 \times 10^{-9}$

#### C.2 Directional Failure Analysis
The result cannot be interpreted merely as a failure to find an advantage for importance. It represents a **catastrophic directional failure** of the tri-factor formulation. Introducing importance weighting ($\gamma = 0.3$) in A7 reduced retrieval precision by **$81.2\%$** relative to A4.

#### C.3 Fourfold Mechanistic Diagnosis
Forensic audit of the memory benchmark and scoring mathematics reveals four distinct mechanisms driving this collapse:

1. **Orthogonal Distractor Advantage**:
   In `SimLab-MemBench-500`, importance scores are static values between $4.01$ and $6.00$ assigned during memory insertion. The mean importance of ground-truth target memories across the 100 queries is $5.2364$. In contrast, the 500-memory pool contains an average of $188.4$ distractors ($37.7\%$) with importance scores higher than the target memory. Because importance is determined by prompt salience rather than semantic relevance to the query, these distractors receive an automatic structural head start.
2. **Min-Max Normalization Scale Compression**:
   The Smallville scoring formulation applies per-query min-max normalization across all candidates:
   $$s_{\text{imp, norm}} = \frac{s_{\text{imp}} - \min(s_{\text{imp}})}{\max(s_{\text{imp}}) - \min(s_{\text{imp}})}$$
   Because raw importance spans a narrow interval ($[4.01, 6.00]$), min-max normalization expands this interval across the entire $[0.0, 1.0]$ range. When weighted at $\gamma = 0.3$, importance adds up to $+0.300$ to the retrieval score. A distractor with importance $5.80$ achieves a normalized score of $\approx 0.90$, adding $+0.270$ to its ranking. A relevant target memory with importance $5.00$ receives normalized score $\approx 0.50$, adding only $+0.150$. The resulting $+0.120$ scoring advantage systematically elevates hundreds of semantically irrelevant memories above the target.
3. **Query Stratification Sensitivity**:
   - *Recency-Sensitive Queries*: When a query requires recent episodic context, A4 achieves $\text{MRR} = 0.7229$. In A7, importance noise reduces MRR to $0.0904$ (a loss of $-0.6325$ MRR).
   - *Temporal-Conflict Queries*: When an older belief must be updated by a recent event, A4 achieves perfect retrieval ($\text{MRR} = 1.0000$). In A7, distractors with high importance overpower recency, crashing MRR to $0.1549$ (a loss of $-0.8451$ MRR).
   - *Relevance-Dominant Queries*: In pure semantic retrieval without recency, adding importance in A6 ($\beta=0.7, \gamma=0.3$) drops MRR from $1.0000$ (A2) to $0.3838$ (a loss of $-0.6162$ MRR).
4. **Simplex Sweep Gradient Verification**:
   The continuous 2D simplex sweep ($N=66$ points) confirms that this behavior is monotonic. As $\gamma$ increases from $0.0$ to $1.0$, retrieval precision steadily deteriorates. The optimal configuration is $(\alpha=0.7, \beta=0.3, \gamma=0.0)$ with $\text{MRR} = 0.6036$. Every tested configuration containing $\gamma \ge 0.3$ produces $\text{MRR} < 0.25$.

#### C.4 Scientific Implication for Generative Agent Memory
These findings indicate that static prompt-assigned importance scoring, as originally formulated in Stanford Generative Agents, represents an **uncalibrated anti-pattern** under dense vector retrieval. Far from acting as a useful cognitive heuristic, it injects static noise that degrades precision. Static importance must not be combined with dense embeddings via unweighted or min-max normalized linear addition.
