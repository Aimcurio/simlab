## 2. Logic Chain

1. **DR-13 Token Derivation**:
   - In round $r$, each of the $N$ agents receives the initial prompt $C_{\text{sys}}$ plus all $(r-1) \cdot N$ historical messages generated by all $N$ agents in rounds $1 \dots r-1$.
   - Each agent generates $L$ completion tokens. Total per agent in round $r$ is $C_{\text{sys}} + (r-1) \cdot N \cdot L + L$.
   - Summing over all $N$ agents and all $R$ rounds yields:
     $$T_{\text{debate}} = \sum_{r=1}^R \sum_{i=1}^N \left( C_{\text{sys}} + (r-1) \cdot N \cdot L + L \right) = N \cdot R \cdot C_{\text{sys}} + \frac{N^2 \cdot R(R-1)}{2} \cdot L + N \cdot R \cdot L \in \mathbf{O(N^2 \cdot R^2 \cdot L)}$$
   - This closed-form derivation resolves the underestimation defect and replaces the broken $O(N \cdot R^2)$ formula in Section 4.1, the latency table in Section 3, the complexity table in Section 4, and Section 6.

2. **DR-12 EXP-001 Sample Size & TOST Reformulation**:
   - To achieve power $1 - \beta \ge 0.85$ for a two-sample proportion test with $p_1 = 0.15, \Delta = 0.15, \alpha = 0.05$, the required effective sample size is $n_{\text{eff\_required}} \approx 137.6$ per condition.
   - Accounting for cluster design effect $DE = 1 + (S - 1)\rho = 1 + 4(0.15) = 1.60$ (with $S = 5$ random seeds), the experiment requires $N_{\text{runs}} \ge 360$ per condition ($M \ge 72$ distinct tasks), yielding $n_{\text{eff}} = 225$, achieving power $> 0.95$ (and $\ge 0.85$ even under conservative $DE = 2.60$).
   - To eliminate affirming the null, a formal Two One-Sided Tests (TOST) framework was incorporated with equivalence margin $\delta = 0.05$ (testing $H_{01}: \Delta TCR \le -0.05$ and $H_{02}: \Delta TCR \ge 0.05$).

3. **DR-12 EXP-002 Cochran's Q Matched Block Calibration**:
   - In Cochran's Q test, the sample size parameter in $\lambda = N_{\text{blocks}} \cdot w^2$ is the number of matched blocks.
   - To achieve power $\ge 80\%$ (target $> 90\%$) at $\alpha = 0.01$ and $w = 0.25$, the experiment requires $N_{\text{blocks}} \ge 279$ ($\lambda \ge 17.44$).
   - At 5 seeds per task, the task pool must be expanded from 30 to at least 56 distinct security vulnerability tasks ($N_{\text{blocks}} = 56 \times 5 = 280 \ge 279$), generating $280 \times 3 = 840$ total runs with verified power of $90.3\%$.

4. **DR-12 EXP-003 Firth's Penalized Likelihood**:
   - In $2 \times 3$ factorial designs with binary outcomes and small cell counts ($n = 12$), complete or quasi-complete separation is mathematically inevitable in zero-failure cells.
   - Mandating Firth's penalized likelihood estimation ($L^*(\beta) = L(\beta) + \frac{1}{2} \log |I(\beta)|$) introduces the Jeffreys invariant prior, guaranteeing finite parameter estimates and valid likelihood-ratio test statistics.

5. **DR-15 Governance Hardening**:
   - For NC-02: Mandated asymmetric digital signature verification on all approval objects prior to Cedar context admission, and enforced immutable Content-Addressable Storage URIs (`cas://sha256:<hex_digest>`), strictly prohibiting mutable file paths.
   - For NC-03: Mandated strictly monotonic per-agent sequence counters ($Seq_{\text{agent}} \in \mathbb{N}$) and single-use nonces, rejecting any request with $Seq \le LastSeq$ to eliminate same-tick replay.
   - For NC-05: Extended AST sanitization to string literals via deterministic typed token redaction (`__STRING_LITERAL_TOKEN_<ID>__`), and mandated dual-pass deterministic static linters (Semgrep/Bandit) where high-severity findings reject code without LLM invocation.
   - Added NC-13 (No Cross-Run State Persistence), NC-14 (Anti-Self-Approval Invariant), NC-15 (Model Endpoint & Weight Hash Pinning), and NC-16 (Sandbox Tool Execution Resource Caps) with full 6-part schemas, updated Section 1.1, Section 2 register, Section 3 summary table, and Section 4 commitment.
